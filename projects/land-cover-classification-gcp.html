Land Cover Classification using Google Cloud Platform

A cloud-hosted deep learning system that classifies multispectral satellite imagery into land cover types — built around a custom SpectralFormer model and made transparent with three complementary Explainable AI techniques.

TimelineJan 2025 – Apr 2025

Overview

This project classifies multispectral satellite imagery into land cover categories — forest, herbaceous vegetation, pasture, river, and sea/lake — using a custom SpectralFormer deep learning model. Users upload a satellite image through a web interface, and a cloud-hosted inference pipeline returns the predicted class along with visual explanations of the decision.

System & cloud architecture

The Flask backend is deployed on Google App Engine, with the trained model stored in Google Cloud Storage for scalable inference. The full workflow runs from image upload through preprocessing, cloud-based inference, and finally visualization of the Explainable AI outputs.

The SpectralFormer model

SpectralFormer is a Transformer-based architecture built specifically for multispectral image classification. Rather than relying only on spatial patterns, it learns relationships across spectral bands using Transformer encoders — well suited to satellite imagery where band-to-band correlations carry real information.

Training used the EuroSAT All Bands dataset — 27,000 labeled patches from Sentinel-2 imagery, 13 spectral bands (the model uses the first six), each patch 64×64 pixels. This project focuses on five of the dataset's ten original classes: Forest, Herbaceous Vegetation, Pasture, River, and Sea/Lake.

Results

Explainable AI

To make the model's decisions transparent, three complementary XAI techniques were applied to the same sample image and its spectral bands: Grad-CAM highlights the regions most responsible for the predicted class, LIME approximates the model locally to surface influential regions, and Layer-wise Relevance Propagation (LRP) traces the prediction score back through the network pixel by pixel.

Web application

The web interface lets users upload a satellite image and see the predicted land cover class alongside its Explainable AI visualization.
