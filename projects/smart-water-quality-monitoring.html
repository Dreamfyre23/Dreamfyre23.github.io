Smart Water IoT Monitoring System

An end-to-end IoT solution that continuously measures river water quality — pH, temperature, turbidity, and dissolved solids — and uses machine learning to turn raw sensor readings into a clear, actionable water quality assessment.

Overview

Water pollution is a growing environmental challenge, and continuous monitoring of river water quality is essential for public health and ecosystem conservation. Manual sampling is slow and can't catch problems as they happen.

This project builds an intelligent IoT-based monitoring system that collects, analyzes, and visualizes water quality data in real time — combining embedded hardware, cloud connectivity, and machine learning into a single working pipeline.

How it works

Multiple water quality sensors connect to an Arduino Uno, which reads pH, temperature, turbidity, and total dissolved solids (TDS). An ESP8266 Wi-Fi module transmits these readings to the cloud, where they're stored and processed. From there, an XGBoost model and a Water Quality Index (WQI) calculation turn raw sensor values into an interpretable quality assessment, displayed on a live web dashboard — with automated email alerts firing whenever conditions turn abnormal.

Machine learning & Water Quality Index

Sensor data is assessed using an XGBoost model trained to estimate water potability, alongside a standard Water Quality Index (WQI) calculation that converts raw readings into an intuitive quality band.

WQI Range Water Quality
90 – 100 Excellent
70 – 89 Good
50 – 69 Moderate
25 – 49 Bad
0 – 24 Very Bad

Model training used a public potability dataset of 3,277 samples across pH, temperature, solids, and turbidity features.

Web dashboard & alerts

A web application visualizes live sensor readings and historical trends, backed by a cloud dashboard for remote access. Whenever a reading crosses into an abnormal range, the system automatically emails an alert so issues can be caught early.
